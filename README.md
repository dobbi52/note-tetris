# 음표 테트리스

음표가 2개(가끔 1개, 레벨 3부터 3개) 붙은 블록을 쌓아 가로 한 줄의 박자 합을 딱 4박으로 맞추는 음악 게임입니다. 4박이 되면 꽃이 피며 사라지고, 4박을 넘으면 그 줄이 깨지며 하트를 하나 잃습니다. 하트 3개를 모두 잃거나 블록이 꼭대기에 닿으면 끝납니다.

- 놀이 주소: https://dobbi52.github.io/note-tetris/
- 대상: 4~6학년 (음악 — 음표와 박자)
- 음표: 4분음표·2분음표 → 레벨 3부터 8분음표 → 레벨 5부터 점4분음표
- 레벨 3부터 바닥에서 음표 줄이 올라옵니다.
- 생각 오락실 통합 로그인으로 순위표(이번 주 / 전체, 닉네임마다 최고 점수)에 기록이 올라갑니다.

## 순위표 서버
`server/Code.gs` — 새 구글 스프레드시트의 Apps Script에 붙여 넣고 웹 앱(실행: 나 / 액세스: 모든 사용자)으로 배포한 뒤, 주소를 `index.html`의 `RANK_API`에 넣습니다.
